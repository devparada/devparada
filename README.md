## 💡 Sobre mí

- 💻 **Desarrollador Backend & Full Stack**: Apasionado por la tecnología y el desarrollo de software. Mi base técnica se apoya en la solidez de **Java (Spring Boot)** y **PHP**, creando APIs seguras, robustas y eficientes.
- 🚀 **Frontend moderno & dinámico**: Llevo la disciplina del backend a la agilidad del cliente trabajando con **React**, **Astro** y **TypeScript** para construir interfaces fluidas y orientadas a una gran experiencia de usuario.
- 🗄️ **Bases de datos & Rendimiento**: Disfruto diseñando arquitecturas de datos relacionales (**MySQL, MariaDB, SQLite**) y NoSQL (**Redis, MongoDB**), optimizando consultas para exprimir el máximo rendimiento.
- 🛠️ **Cultura DevOps & Entorno**: Trabajo habitualmente en entornos **Linux**, automatizando flujos con **GitHub Actions** y empaquetando aplicaciones en contenedores **Docker** para asegurar despliegues limpios y confiables.
